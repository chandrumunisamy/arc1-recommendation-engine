# Contributing to ARC1 Recommendation Engine

Thank you for considering contributing to the ARC1 Recommendation Engine! Our goal is to build a robust, reliable and fair recommendation system. We welcome contributions from developers, data scientists, and researchers to help improve functionality, documentation and tests.

## How to contribute

1. **Fork the repository** and create a branch for your feature or bug fix (e.g. `git checkout -b feature/my-feature`).
2. **Set up the environment** following our [README](README.md) and [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
3. **Make your changes** with clear, well‑structured commits. Follow our code style and include documentation and tests where applicable.
4. **Run tests** with `pytest` before submitting your pull request. Ensure all tests pass and add new tests if introducing new functionality.
5. **Submit a Pull Request (PR)** with a clear title and description explaining the problem and your solution. Reference any related issues.

## Code Style

- Use [PEP 8](https://www.python.org/dev/peps/pep-0008/) for Python code and lint with `flake8`.
- Keep functions small and focused.
- Write docstrings for public functions and classes.

## Commit Messages

Write concise commit messages that describe what changed and why. Use the imperative mood (e.g. "Add caching layer").

## Reporting Issues

If you encounter a bug or have a feature request, please open an issue with:
- A clear title.
- A description of the problem or request.
- Steps to reproduce the bug, if applicable.

## Discussions and Support

For questions or proposals that are not bugs or features, start a discussion in the GitHub Discussions tab. We’re happy to help.

## License and CLA

Thank you for helping us improve ARC1!
